Toggle de tema

Único control global de apariencia. Los dos iconos viven siempre en el DOM; el CSS decide cuál se ve según data-theme. El JS sólo mueve el atributo en <html> — nunca toca clases ni innerHTML.

Formularios

Controles de Bootstrap sin modificar; el único override es el color de foco (--accent + halo). Hacé clic en un campo para verlo. Los contenedores llevan max-width explícito: 500px barrio · 540px catálogo · 600px usuario · 800px ítem.

Se gestionan en Catálogos.

La flecha rota 90° al abrir: Bootstrap agrega .collapsed cuando está cerrado.
